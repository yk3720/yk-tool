なぜ Web アプリにしているか

Excel オートシェイプで作る案もあるが、調査の結果 Web 版を選んだ。

  • 所在 · 探しやすさ

    Excel 貼付はシートが散らばり、作った図がどこにあるかわからなくなりやすい。Web なら一か所に集約し、ブラウザから一覧できる。

  • 共有 · 参照

    他者が作ったフローを探しにくい。Web + 保存庫なら課内で参照しやすい。

  • 修正の手間

    オートシェイプは削除 · 貼付の手作業が多い。Web は表を直して再生成するだけで短い。

  • 配布 · 版の揃え

    PC ごとの配布 · 版揃えが大変。Web なら一か所修正で全員が同じ版を使える。

なぜ有料サービスが必要か（本番運用の場合）

いまの URL は個人検証用の無料枠（月 0 円）。叩き台の確認には足りるが、課内の正式ツールとして使い続けるには向かない。
