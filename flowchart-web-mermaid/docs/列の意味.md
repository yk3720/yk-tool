# 列の意味 — フローチャート表（8列）

| 列 | 説明 |
|----|------|
| ID | ノード番号（10, 20…）。他行の接続先にも使う |
| 図形種別 | 端子・処理・判断・入出力・手動入力 |
| 接続先(下) | 下方向の矢印の行き先 ID（判断では Yes 側になりやすい） |
| 接続先(右) | 右方向の矢印の行き先 ID（判断では No 側になりやすい） |
| Level | 同じ行内の横位置（0=左、1=右の分岐） |
| Text1 | 図形に表示する主テキスト |
| Text2 | 補足（2行目） |
| Text3 | 補足（3行目） |

判断を含むフローは **8 列必須**（右分岐がない 7 列では No 矢印が出ません）。
