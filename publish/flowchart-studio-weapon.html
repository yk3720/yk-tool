フローチャートスタジオ

卒業制作として作った、自分の仕事の武器。
ひとことで言うと ──

探す・作図の手間を減らし、伝えることと理解することに集中力を向けやすくする

減らしたいこと

資料を探す時間
図形をつないで作図する時間

向けたいこと

依頼する人は「伝えること」
作る人は「理解すること」

表を直すと図が追従する。ブラウザで開いて見せられる。

ここから、作ったもの・面倒・理由・工夫と苦戦を見ていきます

POINT 1

作ったもの

フローチャートスタジオは、工程を表に書くとフローチャート図を自動生成する Web アプリです。左で対象を選び、右の表を編集し、中央に図が現れます。判断（菱形）から Yes / No に分岐する流れも、表の「下先」「右先」で指定します。

flowchart-studio（デモ画面・分岐あり）
左 対象ナビ

装置や作業を選び、動作を開く

中央 図のプレビュー

判断菱形と Yes / No の分岐

右 表エディタ

種別・接続・文言を表で編集

図の描画にはノードベースUIライブラリ React Flow を利用。表から図を自動生成する考え方は、Excel と Visio をつなぐ Visio Data Visualizer などでも見られる（出典: Microsoft サポート）。

POINT 2

解決する面倒・課題

主だった面倒

Excel などで図形を置き、線でつなぐ作図。フローが増えるほど、形を整える時間が本体の作業を押しのける。

あとから効いてきた面倒

フローが増えると、資料の場所を探す確認にも集中が持っていかれる。探す・作るは「伝える・理解する」の外側にある。

POINT 3

作りたいと思った理由

きっかけの中心は、Excel の作図に時間がかかりすぎたことです。図形の配置や線つなぎが、本来やりたい「中身の伝達と理解」より先に注意力を奪いました。

フローの本数が増えるにつれ、資料を探す時間も面倒になりました。だから「作図を楽にする」だけでなく、「探さずに開ける」ことも、同じ一本の線の上にあります。

POINT 4

工夫したポイントと苦戦したポイント

工夫

  • 表駆動 — 図を直接いじるより、表を直すと図が追従する
  • Webで開ける — ファイルを探さず、ブラウザで見せられる

苦戦

いちばん苦戦したのは、線の引き方とレイアウト（見た目の整い）です。分岐やループが増えるほど、線の交差や配置の調整が難しくなりました。
