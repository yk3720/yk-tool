フローチャート Web アプリ

業務の手順を表で整理し、ブラウザ上でフローチャートに自動変換して確認・保存・画像出力できる Web アプリを開発しています。

対象読者：社内の非IT部門の方　｜　更新：2026年5月

本資料は、現在検討・開発中の取り組みを関係者に共有するための周知用説明です。決裁・予算のご依頼を含みません。

3分で把握

  • 何を：表形式の業務データから、フローチャートを自動生成する Web アプリです。
  • なぜ：図形を1つずつ手で並べる負担を減らし、手順の見える化をブラウザだけで行いたいためです。
  • どうする：表を入力・読み込みすると、処理の流れが矢印付きの図として表示されます。
  • 範囲：基本機能（MVP）は実装済みです。表の画面編集などは順次拡張予定です。
  • お願い：内容をご覧いただき、ご意見・ご感想があればお知らせください。

背景と課題

業務フローや作業手順をフローチャートで示したい場面は多い一方、次のような負担があります。

  • 図形を1つずつ手で配置・整列するのに時間がかかる
  • 表やリストで整理した内容を、図に移すときに形がぶれやすい
  • 特定の PC ソフトや Excel に依存せず、ブラウザだけで完結させたい

目的とゴール

表（または同等のデータ）から一貫したレイアウトのフローチャートを自動生成し、ブラウザで確認・保存・画像として資料に貼れる状態を目指しています。初期の利用は業務・学習用途を想定しています。

作ろうとしているもの

利用の流れは次のとおりです。専門用語は補足のみ記載します。

表で手順・分岐を記述する
図の形・矢印を自動で整える
ブラウザで確認・データ保存・PNG出力

図には、開始・終了、処理、判断（Yes/No）、入出力など、一般的なフローチャートの記号に対応する形を表示します。判断の分岐には Yes / No のラベルを付けます。

できること／今回しないこと

できること（MVP 完了分を含む） 今回しないこと
表データからフローチャートを自動表示する Excel へ図形を直接描画する （理由：スコープ外）
JSON 形式で図の元データを保存・読み込みする ログイン・クラウド上の共同データベース （理由：初版は個人利用想定）
PNG 画像としてダウンロードする Figma のような自由描画キャンバス （理由：自動生成に特化）
1 画面で入力とプレビューを完結する 既存デスクトップ版の完全置き換えの約束 （理由：別プロダクト）

進め方・現状・次の一手

現状：第1段階（MVP）の受け入れ条件は満たしており、サンプルデータからの表示・JSON 保存・PNG 出力が利用できます。表の画面編集や CSV 貼り付けなど、実用面の機能を追加しています。

次の一手：使いやすさの改善（テーマ、エラー表示の分かりやすさなど）を段階的に進めます。

留意点（最大3件）

  • データは主にご利用の端末上で扱う想定です（クラウド同期は初版に含みません）。
  • 公開 URL で共有する場合は、社内ルールに沿った取り扱いをお願いします。
  • 図の見た目は自動レイアウトのため、手作業の細かい位置調整には向きません。

用語

フローチャート
業務の流れや判断の分岐を、矢印と記号で示した図です。
自動レイアウト
表の内容に応じて、図形の位置を自動で決める機能です。手でドラッグして並べる必要はありません。
JSON（ジェイソン）
図の元になるデータを保存するための、テキスト形式のファイルです。再読み込みで同じ図を復元できます。
