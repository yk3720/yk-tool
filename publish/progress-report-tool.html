ここから、このツールの「なぜ」と「どうやって」を一つひとつ解説していきます。

解決したい課題

装置の立ち上げ作業では、毎日のようにトラブルが発生します。担当のメカ設計者は別の工場にいるため直接話せず、現状はスプレッドシートに問題点を書いてメールや口頭で連絡しています。

この「誰かに連絡する」という作業が、積み重なると大きな負担になります。

現状 — 手動で連絡
  • 別工場のメカ設計者に毎回スプレッドシートを共有して説明
  • 上長からの「今どんな状況？」に都度口頭で答える
  • 電気設計者・生産担当者にも個別にステータスを共有
  • 急ぎ対応が重なると連絡が漏れる・遅れるリスク
本来の開発作業に集中できない。
目指す状態 — 自動配信
  • 帰宅中の電車でスマホから入力するだけ。あとは全自動
  • 毎晩22:30にHTMLレポートが自動生成・配信
  • 関係者全員がLINEで同じレポートを同時に確認できる
  • 上長の「今の状態は？」にもレポートURLを送るだけ
「伝える手間」をゼロにする。

全体の流れ

「スマホで入力」から「LINEに届く」まで、全部で5つのステップで動きます。途中の処理はすべて自動です。

1
スマホで進捗を入力 帰宅中・通勤中

作業の完了数・トラブル内容・状態をGoogleスプレッドシートに入力する。スマホで操作できるのでどこでも入力可能。

2
スプレッドシートにデータが蓄積

入力した内容がGoogleスプレッドシートにリアルタイムで保存される。計画内作業・トラブル・状態・優先度などのカラムに整理されて記録される。

3
GASが毎晩22:30に自動起動 完全自動

Google Apps Script（GAS）の時間トリガーが毎晩22:30頃に自動でスクリプトを起動する。手動操作は一切不要。

4
HTMLレポートを生成・公開

GASがスプレッドシートのデータを読み込み、ガントチャート・計画内作業テーブル・不具合対策テーブルを含むHTMLレポートを生成し、GASウェブアプリとして固定URLで公開する。

5
LINEにサマリー＋URLを送信

LINE Messaging API経由で、当日のサマリーテキスト（遅延件数・問い合わせ中の不具合数など）とレポートのURLを送信。関係者はLINEからレポートを即確認できる。

パーツ 1

トリガー — GAS 時間トリガー

Google Apps Script（GAS）の「インストール可能トリガー」を使い、毎晩22:30頃に自動でスクリプトを起動します。設定はGASのダッシュボードから数クリックで完了します。

// 毎晩22:30に自動実行する設定
ScriptApp.newTrigger("sendDailyReport")
.timeBased()
.atHour(22).nearMinute(30)
.everyDays(1).create();

22:30指定でも、実際は22:30〜23:30の間でランダムに実行されます（GASの仕様）。エラーが出ると登録したGmailに自動通知が届きます。

パーツ 2

ソース元 — Googleスプレッドシート

スマホからGoogleスプレッドシートに進捗を入力します。GASは SpreadsheetApp でデータを一括取得します（セルを1つずつ読むと70秒かかる処理が1秒に短縮されます）。

// スプレッドシートからデータを一括取得
const sheet = SpreadsheetApp
.openById("スプレッドシートID")
.getActiveSheet();
const data = sheet.getDataRange().getValues();
パーツ 3

処理 — GAS HtmlService

GASの HtmlService でHTMLテンプレートにデータを流し込み、レポートを生成します。GASウェブアプリとして公開すると固定URLが発行され、LINEからそのURLを開けるようになります。

届ける先 — LINE Messaging API

帰宅中の電車でスマホから入力するシートです。各行が1件の作業またはトラブルに対応します。

入力はスマホから！

GoogleスプレッドシートはスマホアプリでもPCブラウザでも編集できます。帰宅中の電車で今日の進捗を入力しておけば、22:30に自動でレポートが生成・送信されます。入力後は何もしなくていいのがポイントです。

開発ステップ

ツールを完成させるまでの開発の順序です。上から順番に進めることで、各ステップで動作確認しながら積み上げていけます。

1

スプレッドシートのカラム構成を確定・作成

No・日付(登録)・日付(期限)・区分・装置名・内容・現在・総数・状態・優先度・進捗(実績)のカラムを持つシートを作成する。

2

LINE公式アカウントを作成・Messaging APIを有効化

LINE Developers ConsoleでアカウントとMessaging APIチャネルを作成し、チャネルアクセストークンと自分のユーザーIDを取得する。

3

GASでスプレッドシートのデータ読み込みを作成

SpreadsheetApp.openById().getActiveSheet().getDataRange().getValues() でデータを一括取得するスクリプトを作成・テストする。

4

HTMLレポート（ガントチャート・2テーブル）を生成

HtmlServiceでテンプレートHTMLを作成し、ガントチャート・計画内作業テーブル・不具合対策テーブルの3セクションを実装する。

5

LINE Messaging APIでメッセージ送信を実装

UrlFetchApp.fetch() でPush Messageを送信するスクリプトを作成。APIキーは PropertiesService に保存してコードに直書きしない。

6

GASの時間トリガーを毎晩22:30に設定

GASダッシュボードからインストール可能トリガーを設定する。実行タイミングは22:30〜23:30のランダムになる（GASの仕様）。

7

テスト送信・内容確認・調整

手動でスクリプトを実行し、LINEにメッセージが届くか・レポートが正しく表示されるかを確認する。問題があれば修正して完成。

費用ゼロで、毎晩の連絡作業が消える。

Google Apps Script・Googleスプレッドシート・LINE Messaging API（無料プラン）はすべて無料で使えます。スマホで入力した内容が、その日の夜に自動でLINEに届く仕組みが、ゼロ円で実現できます。
